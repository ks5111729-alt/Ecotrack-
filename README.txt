ECOTRACK - HACKATHON PROTOTYPE

Files:
1. index.html  -> website structure
2. style.css   -> website design
3. script.js   -> lightweight AI-style environmental text classification

HOW TO RUN:
1. Keep all 3 files in the same folder.
2. Double-click index.html.
3. Enter an environmental problem.
4. Click "Analyze with EcoTrack AI".

NOTE:
This is a lightweight prototype for the hackathon. It performs keyword-based text classification locally in the browser. A real ML/API model can be connected later.
